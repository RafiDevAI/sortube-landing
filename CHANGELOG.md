# Changelog

All notable changes to the YT Sorter landing page will be documented in this file.

## [1.0.0] - 2026-08-15

### ✨ Initial Release

- **Design System**
  - Playful brutalist aesthetic with hard shadows and bold borders
  - Custom color palette: lavender hero, mint field, peach workflow
  - Inter font family with tight tracking
  - Scalloped wave section dividers

- **Components**
  - Responsive navigation header with mobile menu
  - Hero section with before/after playlist visualization
  - Feature grid with 4 cards showcasing key capabilities
  - How It Works section with 3-step process
  - Split cards section (Built to Run Locally / What You'll Need)
  - Footer with navigation links

- **Technical**
  - Built with Next.js 16.3.1 and React 19
  - Tailwind CSS v4 with custom theme
  - TypeScript for type safety
  - Lucide React icons
  - Fully responsive design
  - SEO optimized with metadata and sitemap
  - Custom 404 page

- **Documentation**
  - Comprehensive README
  - Deployment guide for multiple platforms
  - Customization guide with examples
  - Code comments throughout

### 📦 Dependencies

- next: 16.3.1
- react: 19.2.8
- react-dom: 19.2.8
- lucide-react: ^1.31.0
- tailwindcss: ^4
- typescript: ^5
